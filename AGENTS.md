# Terminal Duel

A Yu-Gi-Oh-style 1v1 turn-based card game. Pure Python 3.12+ (terminal) or vanilla
JS (browser), no dependencies.

## Run

Terminal:
```
python main.py
```

Browser:
```
python -m http.server 8000
# then open http://localhost:8000
```

Mode: vs AI only (CPU takes a random deck).

## Rules

- 4000 LP, 20-card decks, opening hand 4, hand limit 6, max 5 monsters per side.
- Turn: draw (first player skips first draw) → main phase → battle phase → main phase 2 → end.
- 1 normal summon per turn. Lv5-6 monsters need 1 tribute, Lv7+ need 2.
- Monsters have attack/defense positions; summoned monsters can't change position or
  (position-change) the turn they're summoned; a monster may change position once per turn
  and not after attacking.
- Combat: ATK vs ATK (loser destroyed, controller takes the difference; ties destroy both),
  ATK vs DEF (higher DEF = attacker takes difference; higher ATK = defender destroyed,
  piercing monsters deal the excess as damage). Empty enemy field = direct attack.
- Win by reducing opponent LP to 0 or when they can't draw (deck out).

## Files

- `cards.json` — all card definitions + deck lists (`flare`, `tide`). Shared by both versions.
  Generated by `fetch_cards.py` (PokeAPI) — real Pokémon, local sprites in `img/`.
  Fields: `id, name, kind, atk, defense, level, type, img, effect, text`.
  `kind` = "monster" | "spell" | "trap"; spells/traps have no atk/defense/level.
- `fetch_cards.py` — `python fetch_cards.py` regenerates cards.json + downloads
  official-artwork sprites from pokeapi.co. Stat mapping: best offensive stat → ATK
  (×18, rounded to 50), best defensive stat → DEF, BST → level; primary type → effect
  (fire/electric=burn, water/grass/fairy=heal, psychic=draw, fighting/dragon=piercing,
  BST≥580=aura_atk).
- `simulate.py` — `python simulate.py [--games N] [--seed S] [--cap T] [--json out.json]`
  runs headless AI-vs-AI games and reports deck win rates, matchup stats, game
  length, and card usage. `--json sim_report.json` also feeds the browser's
  "SIM ✓" badge in the mid-bar (click it for the stats panel). Use it to balance
  decks (baseline: flare ~75% vs tide ~60%, avg 4.4 turns).
- `img/` — downloaded Pokémon sprites referenced by `card.img`.
- `cards.py` — `CardDef`, `Monster`, `Player` models and JSON loading.
- `engine.py` — duel state, turn flow, combat resolution, effect triggers (terminal).
- `ai.py` — heuristic AI (`take_turn`). Set `ai.DELAY = 0` for headless sims.
- `main.py` — CLI menus, rendering, human command loop.
- `index.html`, `style.css` — browser UI shell and styling.
- `engine.js`, `ai.js` — JS ports of the engine and AI (keep rules in sync with .py).
- `ui.js` — board rendering, click interactions, overlays, game loop.

## Adding a card

Add an entry to `cards` in `cards.json` and its `id` to a deck list.
- Monster effects: `{"trigger": "on_summon"|"on_destroy"|"passive", "type": "burn"|"heal"|"draw"|"piercing"|"aura_atk", "value": N}`
- Spell effects: `{"type": "heal"|"burn"|"draw"|"buff"|"destroy", "value": N}` (buff *equips* to your monster — permanent +ATK while it's on the field, shown as icon strip; destroy hits the opponent's weakest)
- Trap effects: `{"type": "negate"|"destroy_atk"|"counter"}` — set face-down (max 3), fires on the opponent's next attack

## Notes

- `os.system("")` at startup enables ANSI colors on Windows terminals; `cls` writes `\x0c`
  when stdout is piped (harmless, but it scrambles captured-output ordering — test with `-u`).
- Sanity check: run a headless sim by scripting `ai.take_turn` for both players
  (both `Player(..., is_ai=True)`).
